Picsync

WINDOWS x64 · 本地处理

照片按日归档，
原图留在原处。

Picsync 按拍摄日期或文件日期筛选图片。先看扫描预览，再把选中的照片复制到每日文件夹。不移动、不删除原图，也不上传照片。

前往 GitHub Releases 下载

适用于 Windows 10/11 x64。仓库为私有，下载需要登录有访问权限的 GitHub 账号。

归档前，你可以确认什么？

  • 按一天或日期范围筛选
    默认优先读取 EXIF 拍摄日期，读不到时使用修改日期；也可直接选择修改日期或创建日期。
  • 先预览，再复制
    扫描结果会显示图片名称、归档日期和预计目标。确认后才复制归档图片。
  • 重名不覆盖
    同日同名且内容相同则跳过；内容不同时，使用带编号的新文件名。

三步开始

  1. 运行 Picsync，选择来源文件夹和目标文件夹。
  2. 设置日期，点击「扫描预览」并检查结果。
  3. 点击「开始复制」，例如归档到 目标\2026-11-22\IMG_0001.jpg。

支持 JPG/JPEG、PNG、TIF/TIFF、WebP、BMP、GIF 和 HEIC/HEIF。复制原始文件，不转码。
